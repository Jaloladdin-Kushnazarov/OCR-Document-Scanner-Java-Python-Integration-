🛠 Setup instructions (for macOS/Linux)

1. Python o‘rnatilganligini tekshiring
```bash
python3 --version
```
Agar o‘rnatilmagan bo‘lsa:
- Mac: `brew install python`
- Linux (Ubuntu): `sudo apt install python3 python3-pip`

2. Virtual environment yaratish (tavsiya qilinadi)
```bash
python3 -m venv venv
source venv/bin/activate
```

3. Talab qilingan kutubxonalarni o‘rnatish
```bash
pip install --upgrade pip
pip install -r requirements.txt
```
4. Serverni ishga tushurish
```bash
uvicorn main:app --host 0.0.0.0 --port 8000
```
✅ Endi sizning FastAPI serveringiz `http://localhost:8000/ocr` manzilida ishlaydi.
Swagger: 	http://localhost:8000/docs
📦 Python kutubxonalar ro‘yxati (`requirements.txt`):
```
fastapi
uvicorn
python-multipart
pillow
```

📁 Fayl struktura (minimal)
```
/ocr-backend
│
├── main.py                  # FastAPI OCR endpoint
├── requirements.txt         # Kutubxonalar ro‘yxati
└── setup_instructions.txt   # O‘rnatish bo‘yicha yo‘riqnoma
```

Test qilish uchun curl:
```bash
curl -X POST http://localhost:8000/ocr -F "file=@/path/to/your/image.png"
```
